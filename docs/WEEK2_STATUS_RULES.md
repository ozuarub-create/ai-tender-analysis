# Week 2 Compliance Status Rules

- **met**: explicit bidder evidence fully satisfies the tender requirement. Mandatory items cannot be marked met without evidence.
- **partially met**: evidence addresses only part of the requirement, is conditional, or is contradicted elsewhere in the bid.
- **not met**: the bidder explicitly rejects, excludes, deviates from, or conflicts with the requirement.
- **not evidenced**: no sufficient evidence is found or the available evidence is ambiguous. The searched bid documents are recorded.
- **not applicable**: used only when a documented scope justification shows the requirement does not apply.

Ambiguous evidence is never upgraded to met. Missing responses remain not evidenced.
